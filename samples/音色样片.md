# 第一章 一个普通的工作日

早上七点二十分，闹钟响了第二次。他伸手把手机翻过来，屏幕亮起的那一瞬间，屋里又多了一块发白的方形光。窗外还没有完全亮，楼下的早餐店已经升起了第一缕蒸汽，混着面香和一点油烟味，慢慢爬上来。

他给自己倒了一杯水，坐在桌前，把昨天没写完的那份文档打开。屏幕上的光标闪了几下，像是在催他。他想了想，先写下了第一句话：今天要做的事情有三件——把方案改完，把数据核对一遍，然后早一点睡。

这件小事说起来简单，做起来却总是不太一样。

# 第二章 数字、术语与专有名词

这一章专门用来测试数字和术语的读法，因为这是语音合成最容易露出破绽的地方。

先说数字：二零二六年十月四日，下午十四点三十分；圆周率约等于三点一四一五九；折扣是百分之八十五，也就是原价的零点八五倍；这台机器的内存是十三点七吉字节，剩余可用空间约为一百四十点六吉字节。还有一组容易念错的：一千二百三十四，五万六千七百八十九，零点零零七。

再说术语与中英混排：文本转语音，英文写作 text to speech，缩写是 TTS；音频处理常用 ffmpeg，容器格式是 mp4 与 m4b；机器学习里的 machine learning、神经网络 neural network、大语言模型 large language model，都是这本书里会反复出现的词。

最后是单位和符号：二十二千零五十赫兹，十六位，单声道；时长四百三十二秒，约合七分十二秒；文件大小一千一百四十六千字节，也就是一点一二兆字节。这些数字如果念得含糊，听的人就得回头再听一遍。

# 第三章 对话、引号与语气

“你真的打算今天就把它做完？”她端着一杯水站在门口，语气里有一点怀疑，也有一点好笑。

“试试看吧。”他头也没抬，“做不完就明天，反正它也不会跑。”

“上次你也是这么说的。”

“上次不一样。”他终于抬起头，认真地解释，“上次我不知道问题在哪儿，这次我知道了——就是那两行代码，把单位乘了两遍。”

她点点头，没再说什么，转身走了。门轻轻带上，留下很轻的一声响。

屋子里安静下来。他重新看向屏幕，把光标移到那两行代码上，按下了删除键。窗外，早餐店的蒸汽还在往上冒，只是比刚才淡了一些。他忽然觉得，今天大概真的能早一点睡。
